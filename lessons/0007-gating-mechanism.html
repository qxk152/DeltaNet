门控机制：GLA / Mamba2

第 5 课我们看到线性注意力把所有历史压缩进一个固定大小的状态矩阵 $S$，只能累加、无法遗忘； 第 6 课 DeltaNet 用 delta 规则实现了定向擦除——只擦当前 key 对应的那一条记忆。 但 DeltaNet 仍然缺一样东西：对整个旧记忆的快速衰减。

这一课讲另一条改进路线——门控（gating）。它不挑某一条记忆擦除，而是给整个状态矩阵 乘一个衰减系数 $\alpha_t$，让所有旧记忆一起"褪色"。这就是 GLA 和 Mamba2 的核心思想， 也是 GDN 公式中 $\alpha$ 的来源。

7.1 记忆碰撞：线性注意力的老毛病

先回顾问题。线性注意力的递推是纯加法：

$$S_t = S_{t-1} + v_t k_t^\top$$

状态 $S \in \mathbb{R}^{d_v \times d_k}$ 容量固定，但序列可以任意长。当序列长度远超 $d_k \times d_v$ 时， 不同 token 的键值对外积不断叠加，相互干扰——这就是"记忆碰撞"（memory collision）。 更糟的是，早期混进来的噪声信息永远不会被清除，会一直污染后续检索。

一句话：纯加法更新只有"写"，没有"忘"。旧信息只增不减，状态矩阵迟早被噪声填满。

7.2 门控：给记忆装上"遗忘门"

门控的修法很直接：在写入新信息前，先把整个旧状态乘以一个标量 $\alpha_t \in (0, 1)$。

$$S_t = \alpha_t\, S_{t-1} + v_t k_t^\top$$

展开看两步：

  1. 衰减：$\alpha_t S_{t-1}$ —— 所有旧记忆按比例缩小。$\alpha_t$ 越小，忘得越快。
  2. 写入：$+ v_t k_t^\top$ —— 新的键值对外积叠加进来。

关键在于 $\alpha_t$ 是数据相关的——由当前输入 $x_t$ 投影后过 sigmoid 得到， 模型自己学会"这一步该忘多少"。如果当前 token 带来重要的新信息，$\alpha_t$ 可以小一点（多忘旧）； 如果是噪声，$\alpha_t$ 可以接近 1（少忘）。

对比 DeltaNet：DeltaNet 的 $(I - \beta_t k_t k_t^\top)$ 是定向擦除， 只动 $k_t$ 方向上的分量，正交方向的记忆完全保留；门控的 $\alpha_t$ 是全局衰减， 对 $S$ 的每个元素一视同仁地缩小。两种"遗忘哲学"各有取舍——这正是 GDN 要把两者结合的动机（第 8 课）。

7.3 累积衰减：从单步到多步

单步看 $\alpha_t$ 很直观，但要理解长序列上"越远的过去衰减越多"，需要把递推展开。

7.3.1 展开递推

从 $S_t = \alpha_t S_{t-1} + v_t k_t^\top$ 出发，反复代入：

$$S_t = \alpha_t(\alpha_{t-1} S_{t-2} + v_{t-1} k_{t-1}^\top) + v_t k_t^\top = \cdots$$

最终每一项的历史贡献都要乘上从那个时刻到现在的累积衰减：

$$S_t = \sum_{j=1}^{t} \left(\prod_{\tau=j+1}^{t} \alpha_\tau\right) v_j k_j^\top$$

位置 $j$ 写入的信息，到位置 $t$ 还剩多少？等于中间所有 $\alpha$ 连乘：α_{j+1} × α_{j+2} × … × α_t。 越早写入（$j$ 越小），连乘的项越多，残留越少——这就是"越远的过去越模糊"。

7.3.2 用 γ 简化：连乘变除法

每次都算一长串连乘太麻烦。定义累积衰减乘积 $\gamma$：

$$\gamma_j = \prod_{i=1}^{j} \alpha_i$$

那么从位置 $j$ 到位置 $t$ 的衰减系数就是：

$$\prod_{\tau=j+1}^{t} \alpha_\tau = \frac{\gamma_t}{\gamma_j}$$

因为 $\gamma_t = \alpha_1 \cdots \alpha_j \cdot \alpha_{j+1} \cdots \alpha_t = \gamma_j \cdot \prod_{\tau=j+1}^{t} \alpha_\tau$， 两边除以 $\gamma_j$ 即得。一段连乘变成了两个前缀积的除法——这是后面所有衰减计算的简化关键。

7.3.3 数值例子

假设 4 个位置的衰减率都是 $\alpha = 0.9$：

位置 j γ_j（累积衰减） 到 t=4 的残留 γ_4/γ_j
10.90.6561 / 0.9 = 0.729
20.810.6561 / 0.81 = 0.81
30.7290.6561 / 0.729 = 0.9
40.65610.6561 / 0.6561 = 1.0

位置 1 的信息到位置 4 只剩 0.729，位置 3 的还剩 0.9——越近的记忆保留越多。

7.4 矩阵并行形式与 Γ 掩码

把展开式代入输出 $o_t = S_t q_t$，可以把所有时间步写成矩阵并行形式（推导同第 5 课，只是多了衰减）：

$$O = \big((Q K^\top) \odot \Gamma\big)\, V$$

和纯线性注意力 $O = (QK^\top \odot M) V$ 唯一的区别：因果掩码 $M$（0/1 二值）换成了 衰减感知掩码 $\Gamma$：

$$\Gamma_{ij} = \begin{cases} \dfrac{\gamma_i}{\gamma_j} & i \geq j \\ 0 & i < j \end{cases}$$

也就是说，门控线性注意力的并行形式，就是把标准注意力的因果掩码从"0/1 开关"换成"按距离衰减的权重"。 近处的 token 权重接近 1，远处的 token 权重按 $\gamma_i/\gamma_j$ 指数衰减。结构上和标准注意力一模一样， 所以可以复用 Flash Attention 的分块并行框架——这是后面 chunkwise 算法能高效跑起来的根本原因。

工程含义：$\Gamma$ 是逐元素掩码，作用在 $QK^\top$ 上。这意味着门控线性注意力的并行实现 并不需要重写矩阵乘法——只要在算完 $QK^\top$ 后乘上 $\Gamma$ 即可。后续在 Ascend 上移植时， 这一步对应一个 element-wise kernel，而不是 GEMM。

7.5 GLA 与 Mamba2：同一种门控的两种身份

GLA（Gated Linear Attention）和 Mamba2 都用 $S_t = \alpha_t S_{t-1} + v_t k_t^\top$ 这个递推， 区别主要在参数化和视角：

GLA Mamba2 (SSD)
出发点 线性注意力 + 门控 状态空间模型 (SSM)
α_t 参数化 直接投影 + sigmoid A_log + dt_bias（log-space）
分块算法 chunkwise（GLA 论文首创） SSD 分块（结构对偶推导）
数学结构 完全等价（都是 1-秩衰减 + 外积累加）

对算子开发者来说，两者在 kernel 层面几乎可以共用同一套实现。GDN 沿用了 Mamba2 的 A_log / dt_bias 参数化方式——不直接存 $\alpha$，而存 $g = \log \alpha$。 原因有二：

  • 数值稳定：长序列上 $\prod \alpha$ 会下溢。在 log-space 里连乘变加法 $\sum g$，区间衰减比 $\gamma_i/\gamma_j$ 变成减法 $g_i - g_j$ 再 $\exp$，稳得多。
  • 保证衰减：$g = -\exp(A_\log) \cdot \text{softplus}(\cdots)$，前面加负号确保 $g < 0$，从而 $\alpha = e^g \in (0,1)$ 恒成立——模型不可能学出"放大记忆"。

7.6 递推的瓶颈：为什么需要分块

门控递推 $S_t = \alpha_t S_{t-1} + v_t k_t^\top$ 适合推理（逐 token 生成，天然串行）， 但训练时要处理整个序列，递推形式有三个致命问题：

  1. 显存爆炸：PyTorch autograd 要为每个时间步的 $S_t$ 保存中间值用于反向传播，$L$ 个 $d \times d$ 矩阵吃光显存。
  2. 无法用 tensor core：递推核心是外积 $v_t k_t^\top$（rank-1 矩阵）和逐元素加法，没有 $m \times k \times n$ 的标准矩阵乘法块，喂不饱 tensor core，只能用慢 16 倍的 CUDA core。
  3. 串行依赖：$S_t$ 依赖 $S_{t-1}$，序列方向完全串行，无法并行。

7.4 节的纯并行形式 $O = ((QK^\top) \odot \Gamma) V$ 虽然能并行，但复杂度回到 $O(L^2 d)$， 长序列上计算量爆炸。分块并行（chunkwise）算法在两者之间找平衡：把序列切成大小为 $C$ 的块， 块内用矩阵乘法并行（喂饱 tensor core），块间用递推串行传递状态。

测验

问题 1：门控线性注意力 $S_t = \alpha_t S_{t-1} + v_t k_t^\top$ 中，$\alpha_t$ 的作用是什么？
  • 控制新信息 $v_t k_t^\top$ 的写入幅度
  • 对整个旧状态 $S_{t-1}$ 做全局衰减（遗忘）
  • 只擦除 $k_t$ 方向上的旧记忆
  • 把状态矩阵归一化到单位范数
问题 2：累积衰减 $\gamma_j = \prod_{i=1}^j \alpha_i$ 的好处是什么？从位置 $j$ 到位置 $t$ 的衰减系数可以写成？
  • $\gamma_t \cdot \gamma_j$（两个前缀积相乘）
  • $\gamma_t / \gamma_j$（两个前缀积相除），把连乘简化为除法
  • $\gamma_j - \gamma_t$（前缀积相减）
  • $\alpha_t - \alpha_j$（单步衰减相减）
问题 3：门控（$\alpha_t$）和 Delta 规则（$\beta_t$）的"遗忘方式"有何本质区别？
  • 两者都是定向擦除，只是参数名不同
  • 门控是定向擦除，Delta 规则是全局衰减
  • 门控是全局衰减（所有记忆等比缩小），Delta 规则是定向擦除（只动 $k_t$ 方向）
  • 没有区别，数学上完全等价
问题 4：为什么 Mamba2/GDN 用 log-space 存 $g = \log \alpha$，而不是直接存 $\alpha$？
  • 直接存 $\alpha$ 无法保证 $\alpha \in (0,1)$
  • log-space 计算速度更快
  • 长序列连乘 $\prod \alpha$ 会下溢；log-space 里连乘变加法、除法变减法，数值更稳定
  • 因为 sigmoid 输出的是 log 概率
