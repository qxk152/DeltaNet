DeltaNet 与 Delta 规则

上一课我们看到线性注意力只能累加、无法修正，导致检索误差累积。DeltaNet 用Delta 规则（误差修正规则）替换简单的加法更新，让记忆能根据"预测误差"精确修正。 这一课我们从 Delta 规则的直觉出发，推导 DeltaNet 的更新公式，并用实验说明它为什么在上下文检索上远胜线性注意力。

6.1 什么是 Delta 规则？

Delta 规则是神经网络中一个基础的误差修正学习原则。核心思想非常简单： 根据"我们想要的（目标）"和"我们实际得到的（预测）"之间的差值（delta）来调整参数。

直觉上，想象教孩子瞄准靶心：偏左了就往右调，偏右了就往左调，调整幅度取决于偏离多少—— 这正是 Delta 规则的含义。

$$w \leftarrow w + \eta\, (y_{\text{target}} - y_{\text{pred}})\, x$$

其中 $\eta$ 是学习率，$(y_{\text{target}} - y_{\text{pred}})$ 就是"delta"——误差。 误差越大，调整越多；误差为零，不调整。这其实就是梯度下降在最小化 均方误差损失时的一步更新（第2课讲过反向传播，这里是它在最简单场景下的特例）。

6.2 DeltaNet：把 Delta 规则用在记忆状态上

DeltaNet 把这个误差修正原则用在线性注意力的状态矩阵上。 不再简单地累加外积 $v_t k_t^\top$，而是根据预测误差来更新：

$$S_t = S_{t-1} - \beta_t (S_{t-1} k_t - v_t)\, k_t^\top$$

展开看每一项的对应关系，Delta 规则的平行就清晰了：

Delta 规则符号 DeltaNet 中的含义
学习率 $\eta$$\beta_t \in \mathbb{R}$
输入 $x$$k_t \in \mathbb{R}^d$
目标 $y_{\text{target}}$$v_t \in \mathbb{R}^d$
当前预测 $y_{\text{pred}}$$S_{t-1} k_t \in \mathbb{R}^d$

6.2.1 公式逐层拆解：通讯录类比

这个公式看着吓人，其实就五步。我们把状态矩阵想象成一本"名字→电话"的通讯录， 一步一步从公式最里面的括号往外拆。

第①步：查旧值

用旧通讯录，拿当前名字去查，得到"旧电话"。对应公式里的 $S_{t-1} k_t$： 拿旧状态乘上 key，就是在记忆里检索这个 key 当前存了什么。

第②步：算误差

把查出来的旧值和这次送来的新值比一比，差多少就是误差。公式里写成"旧减新" （$S_{t-1} k_t - v_t$），衡量"我记的旧值离该有的新值差多远"。差越大，误差越长。

第③步：乘修正力度

误差乘上 $\beta_t$，决定这次调多狠。$\beta_t$ 越大调得越多，越小调得越轻。

第④步：外积——把误差钉回 key 对应的位置

这步最关键。误差只是一个向量（一维），但状态是一个矩阵（二维的本子）。 要把"这个 key 方向上的误差"写回通讯录，需要一个叫"外积"的操作： 误差向量乘上 key 的转置 $k_t^\top$，撑成一个矩阵增量。 这个增量只在"当前 key 对应的格子"上有值，其它位置全是零—— 所以它精准地只改这一格，不碰别人。

第⑤步：从旧状态里减掉修正量

最后套上负号，把第④步的增量从旧通讯录里减掉。但因为第②步是"旧减新"， 这里一减，负负得正，整体效果就是"往新值的方向，把这个 key 调过去"。

串起来一句话：查旧值 → 算它和新值的差 → 乘修正力度 → 用外积钉回 key 位置 → 从旧状态里减掉这个修正量。

和线性注意力的区别：线性注意力只做"写入"，从来不查旧值，所以同一个 key 来多次就一路累加，越加越乱。Delta 规则每次都先查、再按差值改，所以同一个 key 无论来多少次，最后存的总是最新的、对的值——这就是它能精确检索的根本原因。

6.2.2 另一种直觉：擦除-写入视角

把 $S_{t-1} k_t$ 理解为"从记忆中用当前 key $k_t$ 检索出的旧值"。当我们遇到同一个 key 对应的新 value $v_t$ 时，不是盲目覆盖，而是做一个谨慎的更新：

$$v_t^{\text{new}} = (1 - \beta_t)\, v_t^{\text{old}} + \beta_t\, v_t$$ $$S_t = S_{t-1} - \underbrace{v_t^{\text{old}}\, k_t^\top}_{\text{擦除旧值}} + \underbrace{v_t^{\text{new}}\, k_t^\top}_{\text{写入新值}}$$

其中 $v_t^{\text{old}} = S_{t-1} k_t$ 是检索出的旧值，$v_t^{\text{new}}$ 是新旧值的加权组合， 由动态的 $\beta_t \in (0,1)$ 控制：

  • $\beta_t = 0$：记忆内容完全保留不动
  • $\beta_t = 1$：完全用新值替换旧值
对比线性注意力：线性注意力是 $S_t = S_{t-1} + v_t k_t^\top$，只写不擦。 DeltaNet 是"先擦后写"，而且擦多少、写多少由 $\beta_t$ 自适应控制——这就是它能精确修正的关键。

6.3 DeltaNet 的上下文检索能力：MQAR 实验

MQAR（Multi-Query Associative Recall）是一个衡量模型上下文关联检索能力的合成基准。 任务规则：每个字母关联一个数字，模型要正确回忆查询序列中每个字母对应的数字。

例如给定输入：

A 4 B 3 C 6 F 1 E 2 → A ? C ? F ? E ? B ?

箭头前是键值对，箭头后是要回忆的查询序列。正确输出为 4, 6, 1, 2, 3。

传统的门控卷积和 RNN 模型在这个任务上普遍表现不佳，而 DeltaNet 展现了显著的优势—— 在最难设置下达到接近完美的表现。这一点尤其令人振奋，因为 MQAR 性能与真实语言建模中的 "关联召回命中率"高度相关，而关联召回失败正是亚二次模型相比 softmax 注意力性能差距的主要来源。

为什么这很重要：DeltaNet 在 MQAR 上的完美表现意味着它在精确检索上 有巨大潜力——这正是线性注意力（及其门控变体如 GLA、Mamba）的痛点。 这激发了作者去开发 DeltaNet 的高效训练算法和 kernel 实现。

6.4 为什么 DeltaNet 比线性注意力更擅长检索？——MSE 推导

DeltaNet 的更新规则可以从逐步最小化均方误差（MSE）自然推导出来。 这揭示了它擅长检索的根本原因。

6.4.1 DeltaNet = 对 MSE 损失做一步梯度下降

定义每一步的损失：希望用 $S k_t$ 预测 $v_t$，误差用 MSE 衡量：

$$\mathcal{L}_t(S) = \frac{1}{2} \|S k_t - v_t\|^2$$

对 $S$ 做一步梯度下降（学习率 $\eta_t$）：

$$S_t = S_{t-1} - \eta_t\, \nabla \mathcal{L}_t(S_{t-1}) = S_{t-1} - \eta_t\, (S_{t-1} k_t - v_t)\, k_t^\top$$

令 $\eta_t = \beta_t$，正是 DeltaNet 的更新规则！也就是说，DeltaNet 每一步都在 对"当前 key 对应的预测误差"做一次梯度下降修正。

6.4.2 对比：线性注意力用的是线性损失

而原始线性注意力对应的是一个线性损失（内积），而非 MSE：

$$\mathcal{L}'_t(S) = -\langle S k_t,\, v_t \rangle$$

对其做一步梯度下降（$\eta_t = 1$）：

$$S_t = S_{t-1} - \eta_t\, \nabla \mathcal{L}'_t(S_{t-1}) = S_{t-1} + v_t k_t^\top$$

这正是线性注意力的加法更新！

根本区别：线性注意力最小化的是线性内积损失（只要"大致对齐"就满意）， 而 DeltaNet 最小化的是MSE 损失——它会持续压制大误差。 对于关联检索这种"必须精确"的任务，最小化 MSE 意味着大误差会被强力修正， 所以 DeltaNet 在检索任务上远胜线性注意力。

6.5 与 Test-Time-Training 的联系

DeltaNet 的 MSE 推导揭示了一个有趣的联系：它和 Test-Time-Training (TTT) 在数学上等价。 具体来说，DeltaNet 在两个条件下等同于 TTT-linear：(1) 去掉 layer norm 等非线性组件； (2) TTT 的 mini-batch 大小设为 1。

这并非巧合——两者的核心都是"在推理时对内部状态做梯度下降来适配当前输入"。 DeltaNet 把这个思想嵌入了递归状态更新的每一步。

6.6 从 DeltaNet 到 Gated DeltaNet

DeltaNet 解决了"精确修正"，但还有一个问题：它仍然没有遗忘机制。 状态矩阵只会被 delta 规则修正，不会主动衰减旧信息。在长序列上，旧信息仍会累积。

Gated DeltaNet (GDN) 的思路很自然：把门控（遗忘）和 Delta 规则（修正）结合——先对状态施加门控衰减，再用 delta 规则做精确更新。 这就是 GDN 的核心创新，也是本课程后续的主题。

$$\text{GDN:} \quad S_t = \alpha_t\, S_{t-1} \;(\text{门控衰减}) \quad + \quad \text{Delta 规则更新}\;(\text{精确修正})$$

测验

问题 1：Delta 规则的核心思想是什么？
  • 用更大的学习率加速训练
  • 根据"目标值与预测值的差值"来调整参数
  • 丢弃所有旧记忆只保留最新信息
  • 用 softmax 归一化误差
问题 2：DeltaNet 的更新公式 $S_t = S_{t-1} - \beta_t(S_{t-1}k_t - v_t)k_t^\top$ 中，$(S_{t-1}k_t - v_t)$ 代表什么？
  • 新旧状态矩阵的差
  • 用当前 key 检索出的旧值与目标新值之间的预测误差
  • 学习率
  • 外积
问题 3：为什么 DeltaNet 比线性注意力更擅长上下文检索？
  • DeltaNet 用了更大的状态矩阵
  • DeltaNet 去掉了 softmax 所以更快
  • DeltaNet 每步最小化 MSE 损失，会强力修正大误差；线性注意力只最小化线性内积损失
  • DeltaNet 使用了更多的注意力头
问题 4：DeltaNet 仍未解决的问题是什么？GDN 如何解决？
  • DeltaNet 不能并行训练，GDN 解决了并行
  • DeltaNet 没有遗忘机制，GDN 把门控衰减与 delta 修正结合
  • DeltaNet 状态太小，GDN 扩大了状态
  • DeltaNet 不支持多头，GDN 支持了多头
