神经网络：从零理解

这一课面向完全没有接触过神经网络和深度学习的读者。我们只回答两个问题： 神经网络由哪些部分组成？每个部分起什么作用？目标只有一个——让你在进入后续课程、 读到 GDN 代码时，知道每个东西"是什么、为什么在那里"。

一句话定义：神经网络就是一个靠数据调出来的函数 $f(x) \to y$。 你给它输入 $x$，它产出输出 $y$；所谓"学习"，就是不断调整它内部的一堆数字（参数）， 让输出越来越接近正确答案。

最小的单元：神经元 (Neuron)

神经网络的最小零件是神经元。它做的事可以用一句话讲完： 把若干输入加权求和，再加一个偏置，最后过一个激活函数。

$$y = \text{激活}(w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b)$$

展开看每个部分的角色：

部分 作用 为什么需要它
输入 $x_i$ 喂给神经元的信号（数据的一个特征） 网络要处理的东西，没有输入就没有计算
权重 $w_i$ 决定每个输入"有多重要" 它是可调节的——"学习"就是调它
偏置 $b$ 一个基础平移量，控制神经元"何时开工" 没有它，函数被迫过原点，太死板
求和 把所有输入的影响汇总成一个数 把多维信息压缩成一个决策依据
激活函数 引入非线性（让曲线能弯） 没有它，叠再多层也只等于一条直线
关键区分：权重和偏置是"参数"——它们是网络要学的数字，开始随机、训练中不断更新。 输入和激活函数不是参数：输入来自数据，激活函数是你选定的固定函数。 读代码时看到的 nn.Linear、weight、bias，指的就是这些可学参数。

动手感受：一个神经元的"旋钮"

下面是一个单输入神经元 $y = \text{激活}(w \cdot x + b)$。拖动权重 $w$ 和偏置 $b$， 看看输出曲线怎么变——这正是训练在做的事：不断扭这两个旋钮，直到曲线长成你想要的样子。

权重 w = 1.0    偏置 b = 0.0

试试看：把 $w$ 调成负数，曲线翻转；把 $b$ 左右拉，曲线整体平移。 训练神经网络，本质就是在成千上万个这样的旋钮上，找到一组让总体误差最小的设置。

从神经元到层 (Layer)

一个神经元只能做一个简单的判断。真正的网络把很多神经元并排放在一起，组成一层； 再把一层层的输出串起来，组成整个网络。

  • 一层 = 很多神经元同时算，每个神经元有自己的权重和偏置，看同一个输入的不同方面。
  • 堆叠多层 = 上一层的输出当作下一层的输入。越深，能表达的模式越复杂。

把一层的计算写成矩阵形式，就是你在代码里反复见到的线性层：

$$y = Wx + b$$

这里 $W$ 是把这一层所有神经元的权重排成的矩阵，$x$ 是输入向量，$b$ 是偏置向量。 一个矩阵乘法就同时算完了整层所有神经元——这就是"层"的全部。

衔接：到这里你已经懂了"层"是什么。第1课会接着讲 Transformer / GDN 里用到的具体层：线性层、激活函数(SiLU)、归一化(RMSNorm)、残差连接。 它们都是本课这些基本零件的特定用法。

怎么"学习"：训练循环 (Training Loop)

参数（权重和偏置）一开始是随机的，网络啥也不会。"学习"就是反复走下面这个循环， 用数据把参数一点点调对：

步骤 名称 做什么
1 前向传播 把输入从第一层喂到最后一层，得到一个预测 $\hat{y}$
2 算损失 比较预测 $\hat{y}$ 和正确答案 $y$，得到一个误差分数（损失 $L$）
3 反向传播 倒着算每个参数该往哪个方向调（梯度）
4 更新参数 按梯度方向微调每个权重（梯度下降）

重复这四步成千上万次，损失越来越小，网络就"学会"了。

损失函数：学习的"标尺"

损失函数 $L$ 把"网络预测得有多错"打成一个数字。整个训练就是在最小化损失。

$$L = \text{某种距离}(\hat{y},\ y)$$
为什么必须有损失函数：要优化，先得有一个能打的分。没有损失函数， 就没有"哪个方向是下坡"，训练无从谈起。后续 GDN 算子要手写反向传播， 反向传播算的就是损失对各参数的梯度——详见第2课。

网络基础组成部分总览

把前面所有零件汇总成一张表，这就是"神经网络的组成部分及作用"：

组成部分 作用 是参数吗
输入 $x$ 喂给网络的数据 否（来自数据）
权重 $W$ 决定每个输入的重要性，是层的主体 是（训练中更新）
偏置 $b$ 基础平移，控制激活时机 是（训练中更新）
激活函数 引入非线性，让网络能学复杂模式 否（固定函数）
层（堆叠） 把神经元组织起来，逐层抽象 —
损失函数 衡量预测与答案的差距，训练的目标 否（你选定）
优化器/梯度下降 根据梯度更新参数，让损失下降 否（更新规则）
记住这三点就够进下一课：
  1. 神经网络 = 一堆参数（权重/偏置）组成的函数；"学习" = 调参数。
  2. 一层 = $Wx + b$ 再过激活函数；多层堆叠成网络。
  3. 训练 = 前向 → 算损失 → 反向算梯度 → 更新参数，循环往复。
读懂 GDN 代码时，看到的每个 nn.Linear、weight、norm、loss、backward()， 对应的都是上面这些概念。

测验

问题 1：神经元的"权重"是什么？
  • 喂给网络的输入数据
  • 可学习的参数，决定每个输入有多重要
  • 一个固定的激活函数
  • 预测与答案的差距
问题 2：为什么神经元需要激活函数？
  • 为了加速矩阵乘法
  • 为了把损失降为零
  • 引入非线性，否则堆再多层也只等价于一条直线
  • 为了减少参数数量
问题 3：训练循环的正确顺序是？
  • 更新参数 → 前向传播 → 算损失 → 反向传播
  • 前向传播 → 算损失 → 反向传播 → 更新参数
  • 算损失 → 前向传播 → 更新参数 → 反向传播
  • 反向传播 → 前向传播 → 算损失 → 更新参数
