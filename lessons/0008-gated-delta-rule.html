Gated Delta 规则：GDN 核心

第 6 课 DeltaNet 用 $\beta_t$ 实现定向擦除——只擦当前 key 对应的记忆，正交方向不动； 第 7 课门控用 $\alpha_t$ 实现全局衰减——所有旧记忆一起褪色，但不挑某一条。 两种遗忘机制各有短板：DeltaNet 不能快速清空全局噪声，门控不能精确修正某条记忆。

Gated Delta Networks (GDN) 的核心创新，就是把 $\alpha_t$ 和 $\beta_t$ 放进同一个递推—— 既有全局遗忘，又有定向修正。这一课推导 GDN 公式、用数值例子拆解三步操作，最后从在线学习和 Test-Time-Training 两个视角理解它为什么"就是该这么设计"。

8.1 GDN 公式：门控 × Delta

Gated Delta Rule 的递推公式：

$$S_t = S_{t-1}\Big(\alpha_t\,(I - \beta_t\, k_t k_t^\top)\Big) + \beta_t\, v_t k_t^\top$$

一眼能看到两个熟悉的因子：外层的 $\alpha_t$（门控衰减），括号里的 $(I - \beta_t k_t k_t^\top)$（Delta 规则的擦除矩阵）。 把它们乘开，公式分解为三个操作：

$$S_t = \underbrace{\alpha_t S_{t-1}}_{\text{① 全局衰减}} \;-\; \underbrace{\alpha_t \beta_t (S_{t-1} k_t) k_t^\top}_{\text{② 擦除旧值}} \;+\; \underbrace{\beta_t v_t k_t^\top}_{\text{③ 写入新值}}$$
步骤 操作 来源 作用
①$\alpha_t S_{t-1}$ 门控（第7课）所有旧记忆等比缩小
②$-\alpha_t \beta_t (S_{t-1} k_t) k_t^\top$ Delta（第6课）擦除 $k_t$ 方向上的旧值（先衰减再擦）
③$+\beta_t v_t k_t^\top$ Delta（第6课）写入新的键值关联
注意步骤②的细节：擦除的是 $\alpha_t S_{t-1}$（衰减后的旧状态）里 $k_t$ 方向上的分量， 不是原始 $S_{t-1}$。这保证了"先全局衰减，再在衰减后的基础上做定向修正"的顺序—— 对应 8.4 节在线学习目标函数里参考点 $\alpha_t S_{t-1}$ 的设定。

8.2 数值例子：手算一遍

设 $d_v = d_k = 2$，状态是 $2 \times 2$ 矩阵。初始状态设为单位阵：

$$S_{t-1} = \begin{bmatrix} 1.0 & 0.0 \\ 0.0 & 1.0 \end{bmatrix}$$

回顾第 5 课的约定：$S$ 的列对应 key 空间维度，行对应 value 空间维度。 $S$ 的第 $j$ 列可理解为"key 空间第 $j$ 个基方向上存储的 value 向量"。

当前时间步参数：$k_t = [1, 0]^\top$，$v_t = [0.7, 0.3]^\top$，$\alpha_t = 0.9$，$\beta_t = 1.0$（完全替换）。 $k_t = [1, 0]^\top$ 是一个"地址"——指定在 key 空间第 1 个基方向上读写。

读取 $S k_t$ 是矩阵乘法（$S$ 每行与 $k_t$ 内积）；写回 $\cdots k_t^\top$ 是外积， $k_t^\top = [1, 0]$ 使结果矩阵第二列全为 0，即只动第一列。

第一步：全局衰减

$$0.9 \times \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix} = \begin{bmatrix} 0.9 & 0 \\ 0 & 0.9 \end{bmatrix}$$

所有元素等比缩为 0.9 倍。

第二步：擦除旧值

$$-0.9 \times 1.0 \times \begin{bmatrix} 1 \\ 0 \end{bmatrix} [1 \; 0] = -\begin{bmatrix} 0.9 & 0 \\ 0 & 0 \end{bmatrix}$$

这里 $S_{t-1} k_t = [1, 0]^\top$（取 $S_{t-1}$ 第一列），外积后只有第一列非零。 注意前面乘了 $\alpha_t = 0.9$，擦除的是衰减后的值 $0.9 \times [1, 0]^\top$。

第三步：写入新值

$$1.0 \times \begin{bmatrix} 0.7 \\ 0.3 \end{bmatrix} [1 \; 0] = \begin{bmatrix} 0.7 & 0 \\ 0.3 & 0 \end{bmatrix}$$

最终结果：三者相加

$$S_t = \begin{bmatrix} 0.9 & 0 \\ 0 & 0.9 \end{bmatrix} - \begin{bmatrix} 0.9 & 0 \\ 0 & 0 \end{bmatrix} + \begin{bmatrix} 0.7 & 0 \\ 0.3 & 0 \end{bmatrix} = \begin{bmatrix} 0.7 & 0 \\ 0.3 & 0.9 \end{bmatrix}$$

看清楚发生了什么：

  • 第一列（$k_t$ 指向的 key 维度）：从 $[1, 0]^\top$ 被精确替换为 $[0.7, 0.3]^\top$——先衰减、再擦除、再写入新 value，等价于"用新值覆盖"。
  • 第二列（正交方向）：从 $[0, 1]^\top$ 仅衰减为 $[0, 0.9]^\top$——只受全局 $\alpha_t$ 影响，没被擦除也没被写入。
调节两个旋钮：若 $\alpha = 1$（不衰减），第二列完全不动，GDN 退化为 DeltaNet； 若 $\beta = 0$（不修正），只有全局衰减、没有定向替换，GDN 退化为门控线性注意力。 $\alpha$ 控制"忘多快"，$\beta$ 控制"修多准"——两者正交，模型可以同时学到快速遗忘和精确检索。

8.3 在线学习视角：四种模型的目标函数

线性 RNN 的隐状态更新可以用在线学习的思路统一理解：把 $S_t$ 看作一个"模型"， 每个新 token 提供一对 $(k_t, v_t)$ 作为样本，更新规则是某个目标函数关于 $S_t$ 的解。 四种模型对应四个目标函数，差别只在"参考点"和"关联项"：

模型 目标函数 更新规则
线性注意力 $\|S_t - S_{t-1}\|_F^2 - 2\langle S_t k_t, v_t\rangle$ $S_t = S_{t-1} + v_t k_t^\top$
Mamba2（门控） $\|S_t - \alpha_t S_{t-1}\|_F^2 - 2\langle S_t k_t, v_t\rangle$ $S_t = \alpha_t S_{t-1} + v_t k_t^\top$
DeltaNet $\|S_t - S_{t-1}\|_F^2 - 2\langle S_t k_t, \beta_t(v_t - S_{t-1} k_t)\rangle$ $S_t = S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top$
GDN $\|S_t - \alpha_t S_{t-1}\|_F^2 - 2\langle S_t k_t, \beta_t(v_t - \alpha_t S_{t-1} k_t)\rangle$ $S_t = S_{t-1}(\alpha_t(I - \beta_t k_t k_t^\top)) + \beta_t v_t k_t^\top$

目标函数两项各自的含义：

  • 第一项 $\|S_t - \text{参考点}\|_F^2$：正则项，约束新状态不要偏离参考点太远。线性注意力和 DeltaNet 的参考点是 $S_{t-1}$（不主动遗忘）；Mamba2 和 GDN 的参考点是 $\alpha_t S_{t-1}$（先衰减再约束）。
  • 第二项 $-2\langle S_t k_t, \cdots\rangle$：关联项，鼓励 $S_t$ 在 $k_t$ 方向上编码 $v_t$。线性注意力和 Mamba2 用 $v_t$ 直接关联；DeltaNet 和 GDN 用 $\beta_t(v_t - \text{旧值})$ 关联误差——这就是 delta 修正的来源。
GDN = Mamba2 的参考点 + DeltaNet 的误差关联。把表格右下角的 GDN 目标函数和上面三个对比： 它的第一项跟 Mamba2 一样（带 $\alpha_t$ 衰减参考点），第二项跟 DeltaNet 一样（带 $\beta_t$ 误差修正）。 GDN 不是凭空发明，而是把两个各自有效的改进"自然拼"在一起。

8.4 TTT 视角：带权重衰减的梯度下降

第 6 课讲过，DeltaNet 的更新规则可以从Test-Time-Training (TTT)角度理解： 对损失 $\mathcal{L} = \frac{1}{2}\|S k_t - v_t\|^2$ 做一步梯度下降，$\beta_t$ 是学习率。

GDN 在此基础上加了 $\alpha_t$。把 GDN 公式改写成等价形式：

$$S_t = \alpha_t S_{t-1} - \beta_t\,(\alpha_t S_{t-1}\, k_t - v_t)\, k_t^\top$$

这就清晰了：先对参数做一步自适应权重衰减（$S \leftarrow \alpha_t S$）， 再在衰减后的参数上对 MSE 损失做一步梯度下降。这与 AdamW 中 weight decay 的角色完全一样—— 在梯度更新前先把参数往零拉一点，防止旧记忆过度累积。

两个视角不矛盾：在线学习视角回答"每种更新规则在最优解什么目标"，TTT 视角回答"更新过程本身对应什么优化算法"。 对算子实现者，TTT 视角更有用——它告诉我们 GDN 的递推本质是"衰减 + 一步 SGD"，所以 recurrent kernel 的循环体 就是这两步操作（第 10 课会看到对应代码：先 b_h *= exp(b_g)，再算 delta 项）。

8.5 为什么 GDN 优于单一机制

用第 6 课"猫狗鸟"的例子对比三种机制。假设记忆里有三条：猫→在窗台上、狗→在院子里、鸟→在树上。 当前 token 带来 $k_t =$ "猫"、$v_t =$ "坐在垫子上"。

条目 更新前 门控 (α=0.9) Delta (β=1) GDN (α=0.9, β=1)
猫在窗台上 0.9×在窗台上 + 坐在垫子上 坐在垫子上（覆盖） 坐在垫子上（先衰减再覆盖）
狗在院子里 0.9×在院子里 在院子里（不动） 0.9×在院子里（衰减）
鸟在树上 0.9×在树上 在树上（不动） 0.9×在树上（衰减）
  • 纯门控：猫的旧值没被清除，只是变小后叠加新值——检索"猫"会得到混合结果，精度差。
  • 纯 Delta：猫被精确替换，但狗和鸟永不衰减——长序列上陈旧噪声累积，无法遗忘。
  • GDN：猫被精确替换（定向修正），狗和鸟逐步衰减（全局遗忘）——既有精度又有遗忘能力。

实验上，GDN 在 MQAR 检索任务和长序列语言建模上都优于 GLA 和 DeltaNet——这正是 Qwen3.5 选用它的原因。

测验

问题 1：GDN 公式 $S_t = S_{t-1}(\alpha_t(I - \beta_t k_t k_t^\top)) + \beta_t v_t k_t^\top$ 展开后的三步操作顺序是？
  • 写入新值 → 全局衰减 → 擦除旧值
  • 全局衰减 → 擦除旧值 → 写入新值
  • 擦除旧值 → 写入新值 → 全局衰减
  • 三步顺序无关紧要，结果一样
问题 2：8.2 节的数值例子中，为什么最终状态 $S_t$ 的第二列从 $[0,1]^\top$ 变成了 $[0, 0.9]^\top$ 而不是 $[0, 0.7]^\top$？
  • 因为写入了新值 $v_t = [0.7, 0.3]^\top$
  • 第二列在 $k_t = [1,0]^\top$ 的正交方向上，只受全局衰减 $\alpha_t = 0.9$ 影响，没被擦除也没被写入
  • 因为 $\beta_t = 1$ 把第二列清零了
  • 计算错误，应该是 $[0, 0.7]^\top$
问题 3：从在线学习视角看，GDN 目标函数的第一项 $\|S_t - \alpha_t S_{t-1}\|_F^2$ 与 DeltaNet 的 $\|S_t - S_{t-1}\|_F^2$ 区别意味着什么？
  • GDN 的正则项更强
  • GDN 的参考点是衰减后的 $\alpha_t S_{t-1}$，即"先遗忘再约束"；DeltaNet 的参考点是原状态，不主动遗忘
  • GDN 没有 delta 修正
  • 两者数学上等价
问题 4：从 TTT 视角，GDN 相比 DeltaNet 多了什么？
  • 多了一步动量（momentum）
  • 在梯度下降前对参数做了自适应权重衰减（类似 AdamW 的 weight decay），对应 $\alpha_t$
  • 把学习率 $\beta_t$ 改成了自适应的
  • 把 MSE 损失换成了交叉熵
