Transformer

Gated DeltaNet 是自注意力的替代品。要理解 GDN 改进了什么，必须先理解 Transformer——它的工作原理、它的瓶颈、以及推理时的 KV Cache 问题。这一课把 Transformer 从文本输入到完整 Block 讲清楚，并用「我爱学习」这个例子手算一遍注意力。

先看全貌：每个组件为什么存在

在拆解细节前，先用一张表回答"每个组件解决什么问题、没有它会怎样"。这样你后面读代码时， 每个模块都"事出有因"。

组件 解决的问题 没有它会怎样
词嵌入 把离散 token 变成连续向量，让网络能算 token 只是整数编号，无法做矩阵乘法、学不到语义
位置编码 给每个位置打标签，因为注意力本身不区分顺序 "狗咬人"和"人咬狗"对模型完全一样，语序丢失
自注意力 让每个 token 看其他 token，按相关性聚合上下文 每个 token 只能自顾自，无法理解上下文
多头注意力 并行多种关注模式（语法、语义、位置……） 一个头只能学一种关系，表达力不足
前馈网络 FFN 对每个 token 独立做非线性变换，增加表达力 只有注意力的模型仍是"线性叠加"，复杂映射学不动
残差连接 让梯度直通，深层网络可训练 层数一多梯度就消失，网络训不动
归一化 把每层输入拉回合理范围，稳定数值 数值爆炸或消失，训练不稳定

从文本到向量：词嵌入 + 位置编码

词嵌入 (Token Embedding)

文本是离散的 token，计算机只能存成整数 ID。但整数 ID 没有"语义"——ID 为 5 和 6 的两个词未必相似。 词嵌入是一张可学习的查找表，把每个 ID 映射成一个连续向量：

$$x = \text{Embedding}[\text{token\_id}] \in \mathbb{R}^{d}$$

训练中这张表和权重一起更新，最终语义相近的词向量也相近。后续所有计算都在向量上进行。

位置编码 (Positional Encoding)

注意力计算 $QK^\top$ 时，理论上打乱 token 顺序结果不变（置换不变）。但语言里顺序至关重要。 位置编码给每个位置附加独有信号：

$$x_t = \text{Embedding}[\text{token}_t] + p_t$$

现代模型（含 GDN）多用旋转位置编码 (RoPE)——不在输入上加位置，而是旋转 Q、K 向量， 使它们的内积自然带相对位置信息。

自注意力：核心机制

三个角色：Q / K / V

对于序列中每个 token，自注意力计算它对其他所有 token 的"关注程度"，再据此聚合信息。三个角色：

角色 符号 比喻
Query (Q) $q_t$ "我想知道什么" — 当前 token 的查询
Key (K) $k_i$ "我有什么" — 其他 token 的标签
Value (V) $v_i$ "我的内容" — 其他 token 的信息

Wq / Wk / Wv 是什么、怎么来的

Q、K、V 不是凭空出现的，而是同一个输入向量 $x$ 经过三个不同的线性层投影出来的：

$$Q = x W_q, \quad K = x W_k, \quad V = x W_v$$

这里 $W_q, W_k, W_v$ 是三个权重矩阵。关于它们，记住三点：

  1. 它们是可学习参数——和第0课讲的权重一样，开始随机初始化，训练中由反向传播（第2课）不断更新，目标是让损失下降。
  2. 同一个 $x$，三种投影——同一个输入向量，被三个不同的矩阵分别投影成"查询者""被查者""内容提供者"三种身份。这就解耦了"提问"和"应答"。
  3. 为什么要分三个？因为"我要找什么"(Q)、"我能被什么匹配"(K)、"我实际贡献的信息"(V)是不同的角色。如果令 $Q=K=V=x$（不投影），模型会退化、表达力大减。
读代码时：你看到的 self.q_proj = nn.Linear(d, d, bias=False) 就是 $W_q$； k_proj 是 $W_k$；v_proj 是 $W_v$。它们内部各存着一个 $d \times d$ 的权重矩阵， 训练时自动更新。GDN 也有这三个投影，完全一样。

手算例子：「我爱学习」走一遍注意力

为了把上面讲的所有东西落到具体数字，我们手算一遍。取 $d=2$（真实模型是 $d=4096$，这里为可读性）， 4 个 token 的嵌入向量，以及三个权重矩阵（实际中这些矩阵是训练学出来的，这里用简单数字演示计算流程）。

计算公式总结

把手算的流程写成一条公式（加上省略的缩放）：

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d}}\right) V$$

除以 $\sqrt{d}$ 防止点积过大导致 softmax 饱和（分数大的被压成1、小的全归0，梯度消失）。

因果掩码：生成式模型的关键

语言模型生成文本时，每个 token 只能看到它之前的 token（不能偷看未来）。这通过把上三角的注意力分数设为 $-\infty$ 实现：

从单头到多头注意力

单头 = 一组 Wq / Wk / Wv

前面手算的例子就是单头注意力：整个模型只有一组 $W_q, W_k, W_v$， 做一次注意力计算，得到一个输出。它的局限是：一组投影只能学一种关注模式。

多头 = 多组 Wq / Wk / Wv

实际模型用多头注意力——并行运行多个"头"，每个头有自己的一组 $W_q^{(h)}, W_k^{(h)}, W_v^{(h)}$， 各学不同的关注模式：

  • 头1 可能学语法关系（主语-谓语）
  • 头2 可能学语义关系（同义词）
  • 头3 可能学位置关系（相邻 token）

设头数为 $H$，每个头维度 $d_h$，满足 $H \times d_h = d$。每个头独立做注意力， $H$ 个头的输出拼回来再过一个输出投影 $W_o$：

$$\text{head}^{(h)} = \text{Attention}(x W_q^{(h)},\ x W_k^{(h)},\ x W_v^{(h)})$$ $$\text{MultiHead}(x) = [\text{head}^{(1)}; \cdots; \text{head}^{(H)}]\, W_o$$

实现技巧：一个大矩阵 = 拼接的多个小矩阵

代码里不会真的创建 $H$ 组小矩阵。而是用一个大 $W_q$（$d \times d$）一次投影完， 再按头拆分（reshape 成 $H \times d_h$）。这和"多组小 $W_q^{(h)}$"数学等价，但只需一次矩阵乘法，更高效：

# hidden_size=512, num_heads=8, head_dim=64
x:     [B, T, 512]       # 输入
q:     [B, T, 512]       # 一个大 Wq 投影后还是 512
q:     [B, T, 8, 64]     # reshape 拆成 8 个头，每个 64 维
q:     [B, 8, T, 64]     # 转置，让头维度在前

# 每个头独立做注意力 (64 维向量之间)
# 8 个头的结果拼回 512 维 → 过 W_o
关键：单头 vs 多头，本质区别就是几组 $W_q/W_k/W_v$。 单头=1组，多头=$H$组。每个头看到的是同一输入的不同投影子空间。 GDN 默认 num_heads=6, head_dim=256，所以 key_dim = 6×256 = 1536。

GDN 的多头差异

GDN 与标准注意力在多头上的一个重要差异：K 和 V 的维度可以不同。

# 标准注意力: head_dim = head_k_dim = head_v_dim (K和V同维度)
# GDN:       head_k_dim = 256,  head_v_dim = 512 (expand_v=2)
#            状态矩阵 S: [256, 512] 而非 [256, 256]

这意味着 GDN 的状态矩阵可以是"长方形"的——用较小的 key 维度检索，存储较大的 value 维度信息。

FFN / MLP 层：逐位置的非线性

注意力层让 token 之间交互信息。之后需要一个逐位置的前馈网络 (FFN)， 对每个 token 独立做非线性变换。现代模型使用 SwiGLU：

$$\text{FFN}(x) = (\text{SiLU}(x W_{\text{gate}}) \odot x W_{\text{up}}) W_{\text{down}}$$

三个线性层：gate 和 up 扩展维度（通常 4×），down 压缩回来。FFN 和注意力的分工： 注意力负责 token 之间混信息，FFN 负责每个 token 内部的非线性变换。两者缺一不可。

残差 + 归一化：让深层可训练

残差连接（$y = x + f(x)$）让梯度能直通，避免深层梯度消失；归一化（RMSNorm）把每层输入拉回合理范围。 这两者（第1课详述）放在每个子层周围。现代模型用 Pre-Norm：

# Pre-Norm: 归一化在残差分支内
h = x + attn(norm1(x))     # 注意力子层
h = h + mlp(norm2(h))      # FFN 子层

完整 Transformer Block

把所有积木拼起来：

class TransformerBlock(nn.Module):
    def __init__(self, hidden_size, num_heads):
        super().__init__()
        self.attn_norm = nn.RMSNorm(hidden_size)
        self.attn = MultiHeadAttention(hidden_size, num_heads)
        self.mlp_norm = nn.RMSNorm(hidden_size)
        self.mlp = SwiGLU(hidden_size, hidden_size * 4)

    def forward(self, x):
        x = x + self.attn(self.attn_norm(x))   # 子层1
        x = x + self.mlp(self.mlp_norm(x))     # 子层2
        return x

为什么需要 GDN：两个瓶颈

O(N²) 瓶颈

注意力矩阵 $A \in \mathbb{R}^{N \times N}$ 是瓶颈的根源：

序列长度 N 注意力矩阵大小 显存 (float16)
2,048 4M 元素 ~8 MB
32,768 1B 元素 ~2 GB
131,072 16B 元素 ~32 GB

KV Cache：推理时的问题

推理（生成）时每生成一个新 token，需计算它与所有历史 token 的注意力。标准做法是缓存历史 K、V：

# 生成第 N 个 token 时:
k_cache.append(k_N)  # 缓存长度不断增长!
v_cache.append(v_N)
scores = q_N @ k_cache.T   # O(N)
o_N = softmax(scores) @ v_cache   # O(N)

KV Cache 大小 = $O(N \times d)$，随序列长度线性增长。长上下文下，缓存显存甚至超过模型本身。

这就是 GDN 要解决的问题：用固定大小的状态矩阵（与 N 无关）替代不断增长的注意力矩阵和 KV Cache。 代价是失去 softmax 的精确检索能力——GDN 通过门控和 delta 规则来弥补（后续课程）。

GDN Block：唯一的不同

GDN 的 Block 结构完全一样，只是注意力层被替换：

组件 标准 Transformer GDN
注意力层 MultiHeadAttention GatedDeltaNet
归一化 RMSNorm RMSNorm (相同)
MLP SwiGLU SwiGLU (相同)
残差连接 Pre-Norm Pre-Norm (相同)
短卷积 无 Q/K/V 各一个 ShortConv

GDN 论文还发现纯 GDN 不如混合架构——大部分层用 GDN，少量层用标准注意力。 例如 24 层模型可能 0–17 层用 GDN（高效长距离压缩），18–19 层用滑动窗口注意力（精确局部检索）。 Qwen3-Next 也采用 GDN + 少量注意力层的混合策略。

理解到这里：你已经知道了一个 Transformer/GDN Block 的完整结构。 后续课程将深入 GatedDeltaNet 层的内部—— 那才是 GDN 的核心，也是你需要在昇腾上实现的部分。

测验

问题 1：Wq、Wk、Wv 是什么？
  • 输入数据，由词嵌入表查出
  • 三个可学习的权重矩阵，把同一个 x 投影成 Q/K/V 三种身份
  • 三个固定的激活函数
  • 损失函数的三部分
问题 2：单头和多头注意力的本质区别是？
  • 多头计算更快
  • 单头不用 softmax，多头用
  • 单头只有一组 Wq/Wk/Wv，多头有多组（每组一个头）
  • 多头不需要残差连接
问题 3：注意力公式中除以 √d 的目的是什么？
  • 减少参数量
  • 防止点积过大导致 softmax 饱和
  • 加速矩阵乘法
  • 实现因果掩码
问题 4：KV Cache 的主要问题是什么？
  • 计算太慢
  • 显存随序列长度线性增长 O(N×d)
  • 精度不够
  • 无法并行化
